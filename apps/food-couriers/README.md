## Environments

This app ships **1 environments** (dev — default: `dev`),
each as a `.env.<name>` file. `npm run env:<name>` copies one over the live `.env`
(restart the bundler with cache reset afterwards). Values are managed in the
designer's **Environments** panel — regenerating refreshes the files.

EAS builds: `eas.json` has one profile per environment (`eas build --profile <name>`);
each sets `APP_VARIANT` + the env's `EXPO_PUBLIC_*` vars, and `app.config.js`
suffixes the app name and bundle/package id for non-default variants so they
install side-by-side. eas.json is created once and then yours to edit.

## Custom code

- Register slot components in `src/custom/index.ts`
  (`registerSlots({ 'Home.beforeContent': MyBanner })`).
- Add new files anywhere under `src/custom/` — they survive regeneration.
- Style it with **Tailwind**: `<View className="p-md bg-primary rounded-lg">`.
  The scale is this design's own tokens, so custom UI and generated screens
  cannot drift. See FEATURES.md.
- Do not edit `src/gen/**`: changes there are lost on the next generate
  (the regen report will warn you first).
